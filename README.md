# 📅 课表小组件 (Scriptable)

用 [Scriptable](https://scriptable.app) 在 iOS 桌面直接看课表，不用每天翻教务系统。

## 功能

- **今日课表**：只看当天的课，一行一节（课名 / 老师 / 教室全名 / 第几节）
- **空课放松模式**：当天没课时自动切换成暖心话（周末与工作日文案不同，按日期固定不跳动）
- **全周课表**：把整周网格画成一张图塞进大尺寸小组件
- **自动算周次**：按「第 1 周周一」基准自动推算当前周，支持**单双周**与**多周段**（如 `1-5 7-18`、`单7-17`、`双8-18`）
- 每天凌晨自动刷新

## 文件说明

| 文件 | 说明 |
|---|---|
| `timetable-today.js` | **推荐**：今日课表小组件（含放松模式） |
| `timetable-widget.js` | 整周网格版（大尺寸小组件） |
| `parse_kb.py` | 解析教务系统导出的「课表.xls」（实为 GBK 编码的 HTML 表格） |
| `schedule.json` | 解析后的课表数据 |

## 使用方法

### 1. 安装 Scriptable
App Store 搜索「Scriptable」免费安装。

### 2. 导入脚本
打开 Scriptable → 右上角 **+** 新建脚本 → 粘贴 `timetable-today.js` 的内容 → 命名「课表」→ Done。

### 3. 添加小组件
桌面长按 → **+** → 搜「Scriptable」→ 选「课表」脚本 → 选 **中号**（课多时用大号）→ 添加。

### 4. 换成你自己的课表
1. 从教务系统导出课表（`.xls` / `.csv` 均可，只要是 HTML 表格）
2. 用 `parse_kb.py` 解析成 `schedule.json`（注意改脚本里的编码转换）
3. 把结果替换掉 JS 里 `const DATA = {...}` 的内容

也可以直接手写 `DATA.courses` 数组：

```js
{
  "d": 5,           // 星期几：1=周一 … 7=周日
  "s": 3,           // 起始节
  "e": 4,           // 结束节
  "n": "机器学习",   // 课程名
  "t": "贾丙静",     // 老师
  "w": "1-3 6-17",  // 周次，支持空格分隔多段 / 单 双 前缀
  "r": "软件实验室(7)-A/B（龙湖图书馆1楼）"  // 教室
}
```

### 5. 改学期基准
脚本顶部：

```js
const BASE_MONDAY = new Date(2026, 7, 31);  // 第 1 周周一（月份从 0 开始，7 = 8 月）
```

## 注意事项

- 课表数据**完全存在脚本里**，不上传任何服务器，隐私安全。
- 周次判断逻辑：`单7-17` = 奇数周的第 7~17 周；`双8-18` = 偶数周的第 8~18 周。
- iOS 小组件刷新频率由系统决定（约 15~30 分钟），点击小组件可手动刷新。
